# Cardify

**جرّب الموقع: [cardify-aam.pages.dev](https://cardify-aam.pages.dev/#/)**

موقع عربي تصمم فيه بطاقة تهنئة، أو بشارة، أو دعوة، أو شهادة شكر، خلال دقيقة. تختار القالب، وتكتب اسمك وتضيف شعارك، وتحمّلها أو تشاركها على طول.

## وش تقدر تسوي فيه

- **التهاني**: رمضان، والعيدين، واليوم الوطني، والتخرج، والزواج، والمولود، وغيرها.
- **البشائر**: تبشّر بخبرك بصيغتك، عن نفسك أو ولدك أو باسم العائلة. مثل عقد القران، والمولود، والتخرج.
- **الدعوات**: دعوة كاملة فيها التاريخ الهجري والميلادي والمكان، ورمز QR يفتح الموقع على الخريطة. وتقدر تطلع دعوة باسم كل ضيف.
- **للمدارس وللشركات**: شهادات وبطاقات برقم تسلسلي ورمز تحقق يثبت إنها أصلية، تُشترى برصيد وتُصدر بالجملة من ملف Excel.
- **رمز QR على البطاقة**: يفتح أغنية، أو صورة، أو موقع، أو رسالة.
- الموقع بالعربي والإنجليزي، ويشتغل على الجوال والكمبيوتر.

## التقنيات

- **الواجهة**: React وVite، والرسم كله على Canvas داخل المتصفح.
- **ملفات PDF وZIP وQR وقراءة Excel**: مكتوبة من الصفر بدون مكتبات خارجية.
- **السيرفر**: Cloudflare Pages Functions، وقاعدة البيانات D1، والملفات على R2.
- **الدفع**: ميسر (مدى، وApple Pay، والبطاقات).

## التشغيل محليًا

```bash
npm install
npm run dev
```

بدون السيرفر، الحسابات والدفع تشتغل في وضع تجريبي داخل المتصفح، فتقدر تجرب كل الصفحات.

## هيكل المشروع

```
src/
  pages/       صفحات الموقع والمحررات ولوحات التحكم
  engine/      رسم البطاقات والدعوات والشهادات
  data/        المناسبات والنصوص والقوالب
  lib/         PDF وZIP وQR وExcel، والاتصال بالسيرفر
server/        الـAPI: الحسابات والرصيد والدفع والتحقق
functions/     نقطة دخول السيرفر في Cloudflare
docs/          أدلة التصميم ودليل الإعداد
```

طريقة الإعداد على Cloudflare وميسر، وإضافة القوالب، موجودة في [docs/SETUP.md](docs/SETUP.md).
