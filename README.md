# Cardify

**جرّب الموقع: [cardify-aam.pages.dev](https://cardify-aam.pages.dev/#/)**

موقع عربي لتصميم بطاقات التهنئة والبشائر والدعوات وشهادات الشكر في دقيقة واحدة. اختر القالب، واكتب اسمك، وأضف شعارك، ثم حمّل البطاقة أو شاركها مباشرة.

## ماذا يقدّم الموقع

- **التهاني**: رمضان، والعيدان، واليوم الوطني، والتخرج، والزواج، والمولود، وغيرها.
- **البشائر**: أعلن خبرك السعيد بالصيغة المناسبة، عن نفسك أو عن ابنك أو ابنتك أو باسم العائلة، مثل عقد القران والمولود والتخرج.
- **الدعوات**: دعوة متكاملة تضم التاريخين الهجري والميلادي والمكان، ورمز QR يفتح الموقع على الخريطة، مع إمكانية إصدار دعوة باسم كل ضيف.
- **للمدارس والشركات**: شهادات وبطاقات تحمل رقمًا تسلسليًا ورمز تحقق يثبت أصالتها، وتُصدر فرديًا أو بالجملة من ملف Excel.
- **رمز QR على البطاقة**: يفتح أغنية أو صورة أو موقعًا أو رسالة.
- يدعم العربية والإنجليزية، ويعمل على الجوال والحاسوب.

## التقنيات

- **الواجهة**: React وVite، ويُرسم كل شيء على Canvas داخل المتصفح.
- **ملفات PDF وZIP وQR وقراءة Excel**: مكتوبة من الصفر دون مكتبات خارجية.
- **الخادم**: Cloudflare Pages Functions، وقاعدة بيانات D1، وتخزين الملفات على R2.
- **الدفع**: ميسر (مدى، وApple Pay، والبطاقات الائتمانية).

## التشغيل محليًا

```bash
npm install
npm run dev
```

عند التشغيل دون الخادم، تعمل الحسابات والدفع في وضع تجريبي داخل المتصفح، ما يتيح تجربة جميع الصفحات.

## هيكل المشروع

```
src/
  pages/       صفحات الموقع والمحررات ولوحات التحكم
  engine/      رسم البطاقات والدعوات والشهادات
  data/        المناسبات والنصوص والقوالب
  lib/         PDF وZIP وQR وExcel، والاتصال بالخادم
server/        واجهة الخادم: الحسابات والرصيد والدفع والتحقق
functions/     نقطة دخول الخادم في Cloudflare
docs/          أدلة التصميم
```
