# Cardify

موقع لتصميم بطاقات التهنئة والبشائر والدعوات وشهادات الشكر. التصميم كله يصير في المتصفح، والحسابات والرصيد والدفع (للشهادات) على Cloudflare.

الموقع أربعة أقسام: **التهاني**، **البشائر**، **الدعوات**، **الشهادات**.

## المزايا

- **التهاني، ١٤ مناسبة**: رمضان، العيدين، اليوم الوطني، يوم التأسيس، يوم العلم، يوم المعلم، التخرج، نهاية العام الدراسي، الزواج، المولود، الترقية، التقاعد، والشكر والتقدير.
- **قوالب بطبقات**: الخلفية صورة أو تصميم مولّد بالكود، والنصوص والشعار طبقات فوقها تُرسم على Canvas.
- **إهداء اختياري**: الاسم فقط، أو «إلى / من».
- **تخصيص**: العبارة (جاهزة أو من كتابتك)، لغة البطاقة، الخط، لون الاسم، لون الهوية، حجم النص، وسحب العناصر بالماوس أو الإصبع.
- **شعار الشركة**: يُرفع ويبقى في جهاز المستخدم فقط.
- **مقاسان**: مربع للمنشورات، وطولي للستوري والحالة.
- **مشاركة مباشرة** من الجوال (واتساب وغيره) عبر Web Share API.
- **بطاقات بالجملة**: قائمة أسماء أو ملف Excel/CSV ← ملف ZIP فيه بطاقة لكل اسم.
- **البشائر**: ٩ أنواع (عقد قران، خطوبة، مولود، تخرّج، حج وعمرة، شفاء، بيت جديد، وظيفة أو ترقية، ختم القرآن). المستخدم يختار الصيغة (أنا / ابني / ابنتي / العائلة)، ويكتب الأسماء، والجملة تتركّب تلقائيًا، أو يعدّلها بنفسه، مع توقيع اختياري.
- **الدعوات**: ١٠ أنواع (زواج، ملكة، خطوبة، تخرج، عقيقة، عزيمة، اجتماع عائلي، تكريم، افتتاح، فعالية). صفحة طولية 1080×1920 فيها البسملة، الداعي («يتشرف / تتشرف / يتشرفان / يتشرف آل»)، الأسماء الكبيرة، اليوم والتاريخ الهجري والميلادي، الوقت (ساعة أو «بعد صلاة العشاء»)، المكان، **رمز QR لرابط الموقع**، ملاحظات (الدعوة خاصة، بدون أطفال، للرجال/للنساء)، وعبارة ختامية. والنص يترتّب ويتحجّم تلقائيًا حسب المساحة.
- **دعوة باسم كل ضيف**: قائمة أسماء أو ملف Excel ← ملف ZIP فيه دعوة لكل ضيف بسطر «حضرة/ فلان».
- **الشهادات المدفوعة (للمعلمين والمدارس والشركات)**: التصميم والمعاينة مجانًا (عليها علامة «معاينة»). العميل يشتري باقة رصيد ويصدر منها على راحته (وحدة، ثنتين، خمس…) لين يخلص. كل شهادة صادرة تنقفل وما تتعدل، وتاخذ **رقمًا تسلسليًا ورمز QR** يفتح صفحة تحقق تثبت إنها أصلية. ٥ تصاميم، ترويسة، شعارات، توقيع، تاريخ هجري أو ميلادي، PDF بمقاس A4، وإصدار بالجملة من Excel.
- **لوحة العميل** (`#/account`): الرصيد، شراء باقة، الشهادات الصادرة مع إعادة تحميلها، المشتريات، بيانات الحساب.
- **لوحة الإدارة** (`#/admin`): المبيعات (آخر ٣٠ يوم)، العملاء وتعديل أرصدتهم، الطلبات، الباقات وأسعارها، وعدد الشهادات المجانية عند التسجيل.
- **الدفع**: ميسر (مدى، فيزا/ماستركارد، Apple Pay، STC Pay حسب المفعّل في حسابك).
- **رمز QR على البطاقات والدعوات**: أغنية (رابط أو ملف صوت مرفوع)، موقع، صورة مرفوعة، رابط، واتساب، أو رسالة.
- **وضع تجريبي**: إذا الموقع اشتغل بدون السيرفر (مثل `npm run dev`)، الحسابات والدفع تشتغل تجريبيًا داخل المتصفح عشان تقدرين تجربين كل الصفحات.
- عربي وإنجليزي، ووضع داكن، وألوان الموقع تتغير حسب المناسبة.

## التشغيل

```bash
npm install
npm run dev
```

النشر على GitHub Pages:

```bash
npm run deploy
```

## تفعيل الحسابات والدفع (Cloudflare + ميسر)

السيرفر موجود في `functions/` و`server/`، وCloudflare Pages يشغّله تلقائيًا مع كل رفع على GitHub. تحتاجين تربطين ٣ أشياء من لوحة Cloudflare مرة وحدة:

**١) قاعدة البيانات (D1)** — إلزامي
1. Cloudflare ← **Storage & Databases** ← **D1** ← **Create** ← الاسم `cardify`.
2. مشروع الموقع في **Workers & Pages** ← **Settings** ← **Bindings** ← **Add** ← **D1 database** ← اسم المتغير `DB` بالضبط ← اختاري `cardify`.
3. الجداول تنشأ لحالها أول ما يفتح أحد الموقع، ما تحتاجين تشغّلين شي.

**٢) التخزين (R2)** — للصور والصوت اللي ينحطون في رمز QR (اختياري)
1. **R2** ← **Create bucket** ← الاسم `cardify-media`. (Cloudflare يطلب بطاقة لتفعيل R2 حتى لو بقيتي في الحد المجاني.)
2. نفس صفحة **Bindings** ← **R2 bucket** ← اسم المتغير `MEDIA`.

**٣) المتغيرات** — في **Settings** ← **Variables and Secrets**:

| الاسم | القيمة |
|---|---|
| `ADMIN_EMAILS` | إيميلك (أو أكثر من إيميل بينها فاصلة). هذا اللي يفتح لوحة الإدارة. |
| `MOYASAR_SECRET_KEY` | المفتاح السري من ميسر (اختاري **Encrypt**). ابدئي بمفتاح التجربة `sk_test_…` |
| `SITE_URL` | اختياري: رابط موقعك النهائي إذا ربطتي دومين، مثل `https://cardify.sa` |

بعدها: **Deployments** ← آخر نشر ← **Retry deployment** عشان تطبّق الإعدادات.

**ميسر**
1. سجّلي في ميسر بوثيقة العمل الحر، وخذي **Secret key** من الإعدادات ← API Keys.
2. جرّبي الشراء بمفتاح التجربة وبطاقات ميسر التجريبية، ولما يشتغل بدّلي المفتاح بـ `sk_live_…`.
3. Apple Pay يحتاج توثيق الدومين من لوحة ميسر.
4. ما تحتاجين تضبطين Webhook: كل فاتورة تُنشأ ومعها رابط الإشعار. السيرفر ما يضيف الرصيد إلا بعد ما يسأل ميسر بنفسه إن الفاتورة مدفوعة وبنفس المبلغ.

**تصيرين أدمن**: سجّلي حساب في الموقع بنفس الإيميل اللي في `ADMIN_EMAILS`، ويطلع لك زر «لوحة الإدارة» في «حسابي».

**الأسعار**: الباقات الافتراضية (١ بـ ١٠ ر.س، ١٥ بـ ٩٩، ٤٠ بـ ١٩٩، ١٢٠ بـ ٤٤٩) وشهادتين مجانًا عند التسجيل. تغيّرينها من لوحة الإدارة.

**عن منع تصوير الشاشة**: المتصفحات ما تسمح لأي موقع يمنع التصوير. الحماية هنا: المعاينة عليها علامة مائية، والشهادة النهائية ما تطلع إلا بعد الخصم من الرصيد، ورمز التحقق يكشف أي شهادة معدّلة.

## التخصيص

### إضافة قالب صورة

1. صمّم الخلفية بمقاس 1080×1080 بدون الاسم، وضعها في `public/templates/`.
2. أضف عنصرًا في `src/data/imageTemplates.js` يحدد المناسبات، ولون الاسم، ومكانه (`y` من 0 إلى 1)، ومكان الشعار.

### إضافة قالب مولّد لمناسبة

أضف `["اسم التصميم", "اسم الألوان"]` إلى قائمة `designs` للمناسبة في `src/data/occasions.js`.

### إضافة شهادة بتصميمك

1. صمّمي الخلفية بمقاس A4 بالعرض **3508 × 2480** بكسل، واتركي المناطق الملونة في `docs/certificate-guide.png` فاضية. تقدرين تحطين الصورة كطبقة مرجعية فوق تصميمك في Canva أو Figma.
2. ضعي الملف في `public/certificates/`.
3. أضيفي عنصرًا في `src/data/certificateTemplates.js` (فيه مثال وشرح لكل خيار: ألوان النص، ومكان كل جزء، وإخفاء العنوان لو كان جزء من تصميمك).

تصاميمك تظهر أول شي في قائمة التصميم، قبل التصاميم الجاهزة.

### دليل تصميم البطاقات

`docs/card-guide.png` يوضح مساحة الاسم والشعار في بطاقة 1080 × 1080.

### إضافة دعوة بتصميمك

1. صمّمي الخلفية طولية **1080 × 1920** بكسل، واتركي المنطقة الوسطى فاضية حسب `docs/invitation-guide.png` (حطيها طبقة مرجعية فوق تصميمك).
2. ضعي الملف في `public/invitations/`.
3. أضيفي عنصرًا في `src/data/inviteTemplates.js` (فيه مثال): أنواع الدعوات اللي يظهر فيها، ألوان النص (`names`, `text`, `muted`, `accent`)، وحدود منطقة النص `area` لو تصميمك يحتاج هوامش أكبر.

النص في الدعوة يترتّب تلقائيًا: لو المحتوى كثير يصغر، ولو قليل يكبر ويتوزّع.

### إضافة بشارة بتصميمك

1. صمّمي خلفية 1080 × 1080 فيها عنوان البشارة، واتركي منطقة النص فاضية حسب `docs/announcement-guide.png`.
2. ضعيها في `public/templates/` وأضيفيها في `src/data/imageTemplates.js` مثل أي قالب صورة، وفي `occasions` اكتبي رقم البشارة (مثل `"ann-aqd"`).
3. مكان النص يتحدد بـ `layout.phrase` (مثل `{ y: 0.55, size: 44, maxW: 0.74 }`)، والتوقيع ينزل تحته تلقائيًا.

### إضافة نوع بشارة أو دعوة

- **بشارة**: انسخي عنصرًا في `src/data/announcements.js`. كل صيغة (`voices`) فيها الحقول المطلوبة والجملة بالعربي والإنجليزي.
- **دعوة**: انسخي عنصرًا في `src/data/invitations.js`: العبارة الافتراضية، العبارة الختامية، وكم اسم يظهر كبير (`names`).

### علم اليوم الوطني

مشهد اليوم الوطني يستخدم ملف العلم الرسمي `public/flags/sa.svg` عشان تطلع الشهادة بخط الثلث الصحيح. إذا الملف مو موجود، يظهر رسم مؤقت مبسّط.

### تعديل سماء الواجهة الرئيسية

كل مشاهد السماء (رمضان، العيد، اليوم الوطني، التخرج) في `src/hero/skyScenes.js`. كل مشهد عنصر في `SCENES` فيه الكلمة اللي تظهر في العنوان ودالة الرسم. تقدرين تغيرين الألوان، أو تحذفين مشهد، أو تنسخين واحد وتعدلينه لمناسبة جديدة. ومدة المشهد في `SCENE_LEN`.

### إضافة مناسبة

أضف عنصرًا جديدًا إلى `OCCASIONS` في `src/data/occasions.js`.
